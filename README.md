# LaptopShopHelper

**What Does It Do?**

This extension checks to see if the laptop or computer you're looking at has good specs or not and if you should buy it by parsing website HTML and using Groq API to determine conclusion.

**How we Built It**

We built this extension using JS and HTML for the parsing, API use, and design of the extension.

**Challanges We Ran Into**

Since we used an AI API, Groq, it was difficult to gain an API that would last long enough for our use case, as well as tring to hide the API key from the published source code. In the beginning we ran into many issues, which significantly reduced our time to produce something. 

**Accomplishments We're Proud Of**

Even though we were running on significantly reduced time, we were proud to get an MVP up and running and submit close to the deadline. 

**What We Learned?**

We learned how to use AI API's to prompt, collect response, format, and post the result to the user. 

**How to run?**

Download the github repo and save it to your computer.
Open Chrome and go to `chrome://extensions/`
Enable "Developer mode" (toggle in top right)
Select the downloaded repo and open the "LaptopShopHelper" folder and stop there, and load the folder into chrome.
Click "Load unpacked"
